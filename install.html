Install Speedesk

Install in one tap Speedesk works offline once installed. No account, no network needed after first visit.
Install on iPhone or iPad
1 Tap the Share button in Safari's toolbar.
2 Scroll down and tap Add to Home Screen.
3 Tap Add. Speedesk appears on your home screen.
Install on Android
1 Open Speedesk in Chrome.
2 Tap the menu (three dots, top-right), then Install app.
3 Tap Install. Speedesk appears on your home screen.
Install on desktop
1 Look for the install icon in your browser's address bar.
2 Click it, then confirm Install. Speedesk opens as its own window.

Speedesk works offline once installed. No account needed.
